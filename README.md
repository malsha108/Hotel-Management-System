# 🏨 Hotel Management System (Java Application)

## 🎯 Overview
A complete Hotel Management System developed using Java (NetBeans IDE). This system helps manage hotel operations including customer check-in/check-out, room booking, employee management, and income tracking.

## 🧩 Key Features
* User Login & Authentication (Manager/Reception)
* Customer Management (Add, Update, Search, Check-in/Check-out)
* Room Management (Add Rooms, Room Change, Update Check-in)
* Employee & Department Management
* Driver & Pickup Service Management
* Income & Billing Reports
* User-friendly Dashboard

## 🛠️ Technologies Used
* Java (Swing / AWT)
* MySQL Database (JDBC Connection)
* NetBeans IDE

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project in NetBeans IDE.
3. Import the database file (`hotel_db.sql`) into MySQL.
4. Update database connection details in `Conn.java` (username/password).
5. Run HotelManagementSystem.java to start the application.
